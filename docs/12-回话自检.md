# 回话自检：用一行标签代替场景枚举

> 背景：加规则是「事后描述」，每遇到一个坏例子补一条，永远追不上对话。
> 这里换一个结构：**让模型在说话前先判断一次**，代码只读判断、不枚举场景。

## 一、为什么不是「五分支判断表」

判断表是**枚举**：要判断 / 陈述 / 随口 / 问事实 / 情绪。
它覆盖已知情况，新情况又要加一行——和规则是同一个问题，只是换了排版。

## 二、做法：一行自检标签

要求模型在回复前先写一行：

```
[自检] 要判断 | 依据=有 来源=记忆
[自检] 陈述 | 依据=- 来源=-
[自检] 问事实 | 依据=无 来源=-
```

格式固定三个字段：**他在要什么 / 我有没有依据 / 依据从哪来**。

然后才是正文。代码：剥离开头这一行，正文照发，标签入库。

## 三、为什么这能覆盖大面积

| 维度 | 规则/判断表 | 自检标签 |
|---|---|---|
| 覆盖范围 | 枚举过的场景 | 模型自己判，未枚举的也能覆盖 |
| 可观测 | 只能看回复 | 标签直接给出「判断比例 / 无依据比例」 |
| 可路由 | 关键词猜 | 按标签决定搜不搜（**用判断替代猜**） |
| 可校验 | 难 | 标签 vs 回复是否一致，可抽样 |

## 四、分三步落地

| 步 | 做什么 | 改行为吗 |
|---|---|---|
| **P1** | 要求输出标签；代码剥离、记录 `data/self_check.jsonl` | 不改（只观测） |
| **P2** | 「要判断 + 依据=无」→ 先搜一轮（替代关键词规则） | 改（路由） |
| **P3** | 「要判断 + 依据=无 + 搜不到」→ 明说没把握，不给结论 | 改（措辞） |

**先 P1 跑一周**：标签和实际回复对不上的样本，就是下一轮的规则来源——但来源是数据，不是拍脑袋。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 模型不按格式输出 | 剥离做容错：没匹配到标签就原样发，不报错 |
| 标签「事后合理化」（先编再补标签） | 标签只做路由/观测，不当真相；用抽样人工校验 |
| 多一行 token | 一行约 15 字，可忽略 |
| 标签格式漂移 | 正则宽松匹配 `\[自检\].*`，字段缺失也接受 |

## 六、判据

- **P1 后**：标签覆盖率（有标签的回复占比）> 90%；「要判断 + 无依据」比例能量化。
- **P2 后**：分析类搜索的触发准确率（相比关键词）不再误伤陈述句。
- **P3 后**：`fact_check` 命中数下降（无依据的判断被说成「没把握」，不再编数字）。
