# 联动矩阵：哪条链路坏了，会被哪个测试发现

> 一句话：**单层全绿不等于接上了**。连续几次事故都是「app_core 测过了、插件也导得进，
> 但两边传的参数不对」。这份表的作用是让每条跨层链路都有一个明确的守门人。

## 怎么跑

```bash
ops/verify.sh            # 六件套（分层 + 离线 + 联动 + 全链路 + 插件 + agentd）
ops/verify.sh --pre      # 重启前：分层 + 离线 + 联动 + agentd（都不碰生产库）
ops/verify.sh --quick    # 秒级：分层 + 联动
```

2026-11-05 实跑：**592 / 47 / 208 / 7 / 70**，6/6 通过。

## 矩阵

| 联动 | 断了会怎样 | 守门测试 | 断言什么 |
|---|---|---|---|
| QQ → 插件入口 | 私聊不回、群聊串私聊 | link-check 动态 4–10 | 真事件驱动 `_handle`，断言「发了几条、发给谁、参数是什么」 |
| 图/文件 + 补一句 → 同一轮 | 被拆成两条互不知情的回复 | link-check 5–7 | 窗口内合并成一轮；只有图时给占位正文 |
| reply 主链路 | 慢、断、发出半截 | 离线 Z + link-check | prompt 顺序、45 秒硬线、流式分段、失败兜底 |
| 记忆写入 → 总结 → 召回 | 它「不记事」或重复记 | 离线 C/P + 全链路 | 幂等、水位、访问计数、召回条数 |
| 矛盾检测 → 取代 → 召回过滤 | 旧事实继续进 prompt | 离线 P2 | 四道闸、superseded 不进召回、软删可恢复 |
| 复盘 → 画像/纠正 → prompt | 学到了但不影响说话 | 离线 Z + 全链路 | 画像进 prompt、排在纪要前、低置信度不注入 |
| 画像变化/过期 → 注入 | 半年前的一句话一直生效 | 离线 profile | changed 不改写措辞、seen 过期、previous 记录 |
| 情绪 → prompt / 节奏 / 主动消息 | 阈值成死代码 | 离线 mood + 派生测试 | 相对基线、衰减可复合、关思考判定 |
| 调度 → 任务 → 推送 → job_runs | 静默漏跑、失败也记「跑过」 | 离线 scheduler | 补跑窗口、缺跑审计、`_unclaim` 撤回 |
| 插件 ↔ agentd | 任务结果丢失、游标乱跳 | link-check 新增 6 条 | 发送失败不推进游标、不 ack、不写历史 |
| 命令 → 权限门 → /help | 群里能敲、或命令没入口 | lint（AST） | 权限门、重名、清单覆盖率 |
| 配置 → 进程 | 改了阈值不生效 | 离线 config | 解析失败可见、mtime 变了会提示重启 |
| 影子 → 周报 | 样本只落盘、没人看 | 离线 shadow | 七路样本能压成行、过期样本不计入 |
| prompt 快照 → /prompt_last | 排障时只有哈希 | 离线 prompt_log | 正文入库、标记可读 |
| 知识库 → 索引 → prompt → 时效 | 过期知识当事实用 | 离线 wiki/kb + 全链路 | 索引/切块/过期标记/归档 |
| 备份 → 回滚 | 出事回不去 | `ops/cloud-backup.sh` + 文档 | 手工验证（不在自动套件里） |

## 覆盖不到的地方（别假装覆盖了）

- **真实 QQ 收发**：测试用假 bot，只验证「调了什么 API」，不验证 OneBot 那边真的送达
- **模型输出质量**：只有影子样本，没有自动判定「这句话好不好」
- **agentd 真沙箱**：单测用 `FakeSandbox`，真 docker 执行要手工验（见 docs/03 十三）
- **定时到点**：测试直接调 `_run_*`，不等真实时钟；到点逻辑靠 `_due()` 单测
- **并发竞态**：只有会话锁与游标相关的少量用例

## 加一条联动时

1. 先问「断在哪一层」——函数级 bug 归离线回归，接线 bug 归 link-check
2. 断言**调用次数和参数**，不是「没崩」：`check("只发一次", len(sent) == 1)`
3. 用例之间清状态（游标、日志文件、模块级缓存），否则顺序一换就红
