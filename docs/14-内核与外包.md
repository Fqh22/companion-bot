# 内核与外包

> 什么该自己做、什么该引外部，用四个问题判，不靠感觉。

## 判据

1. **它影响每一轮吗？** 是 → 内核。
2. **它需要跨轮记住结果吗？** 是 → 内核。
3. **它失败时能不能只降级、不崩？** 能 → 可以外包。
4. **它涉及用户数据长期滞留吗？** 是 → 内核（或至少本地）。

一句话：**这次调用的结果，要不要影响下一次？** 要 → 内核；不要 → 外包。

## 内核：必须自己具备

| 能力 | 为什么 |
|---|---|
| 记忆（写 / 召回 / 矛盾 / 时效 / 遗忘） | 跨轮状态，接住的前提 |
| 情绪 | 每轮影响表达，且要连续 |
| 判断（要安慰 / 分析 / 接梗） | 每轮都做，且要前后一致 |
| 节奏（分段 / typing / pacing） | 接住的剂量 |
| 人格与风格 | 决定「像不像它」 |
| 对话组装（历史 / 背景 / 预算） | 每轮都要，依赖状态 |
| 调度与主动消息 | 时机依赖状态与关系 |
| 关系（称呼 / 共同经历 / 雷区） | 跨轮稳定，且私密 |

**共同点：有状态、要连续、决定「怎么接」。**

## 外包：外部引用

| 能力 | 为什么 |
|---|---|
| ASR（语音→文字） | 一次性、无状态、失败可降级 |
| 视觉（图→描述） | 同上 |
| 搜索（联网） | 一次性，用完即弃 |
| 生成（LLM） | 模型本身是外部；风格由内核 prompt 约束 |
| 嵌入（embedding） | 纯计算，无状态 |
| TTS（文字→语音） | 一次性 |
| 文件解析（PDF/Office→文本） | 一次性转换 |

**共同点：一次性、可替换、失败能降级。**

## 边界模糊的三项

| 能力 | 判断 | 理由 |
|---|---|---|
| 知识库（wiki） | 内核 | 带时效的记忆，要召回、要过期 |
| 提醒 / 任务 | 内核 | 有状态机，跨轮 |
| 表情包 | 内核 | 语气的一部分，选哪张依赖情绪 |

原料可以外包：网页抓取、图片下载、文件解析。

## 代码约定

- 外包模块：`web` `asr` `llm`（未来还有 tts / ocr）。它们只做「一次调用 → 一个结果」，
  不持有跨轮状态。
- **只有装配点和热路径可以 import 外包**：`chat` / `chat_turn` / `memory` / `tools` / `engine`。
  其它模块要外部能力，走这些模块的接口。
- 检查：`ops/lint-layers.py` 的 `check_outsourced`（当前是 WARN，先观察）。

## 换掉它还是不是「它」

| 换掉 | 还是它吗 |
|---|---|
| ASR | 是（只是听不清） |
| 视觉 | 是（只是看不见图） |
| 搜索 | 是（只是不联网） |
| LLM | 大概率是（记忆/情绪/关系还在，风格会变） |
| 记忆 | **不是** |
| 情绪 | **不是** |
| 判断 | **不是** |

**能换的都可以外包；不能换的必须自己做。**
