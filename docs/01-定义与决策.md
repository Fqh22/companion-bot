# 01 · 定义与决策

> **L1 · 它是什么。** 下一层：[02 系统与扩展](02-系统与扩展.md) · [03 运维与通道](03-运维与通道.md) ·
> [04 评测与实验](04-评测与实验.md) · [05 改动台账](05-改动台账.md)。
> 状态：稳定（2026-11-16 重写，合并旧 00 / 09 / 10 / 22）。用户圈定方向 **A + B + C**。

## 1 · 一句话

**它是一个可携带、跨月连续的陪伴主体**：记得住你说过什么，更知道什么时候不该提、
怎么说才不冒犯，并且能在你授权下把小事办完。

不是聊天机器人，不是记忆库，不是任务执行器。本体是**一个「谁」**——跨会话、跨通道、
跨模型仍被认出来的同一个人。项目自 2026-10-31 起在单用户环境下持续运行。

## 2 · 本体与三支柱

记忆、表达、判断是它的**能力**，不是它的身份；通道、模型、记忆引擎都是可换的**零件**。

| | 支柱 | 内容 |
|---|---|---|
| **第一** | **判断 / 克制** | 听见了吗、有去处吗、剂量对吗；真正的接住包含「不接」。最难的是**什么时候不检索、不追问、不主动开口** |
| 第二 | **记忆（资源）** | 事实可追溯、矛盾可裁决、表达不污染事实；只在该用的时候被调用，不是每轮都翻 |
| 第三 | **表达（出场）** | 语气、节奏、形式、沉默；形式本身携带意图（`app_core/message.py` 的 `Part`） |

设计理念是「**似人，但不是人**」：保留情绪与连续性，不接受静默遗忘、失真与人格漂移。
事实要求精确、可溯源、矛盾可裁决；表达要求口语、有停顿、懂克制。两层不互相污染。

## 3 · 三个不可让步的属性

- **连续性（A）**：一个主体、一段关系；不做多租户，不做一人千面。
- **可携带性（B）**：人格、记忆、关系状态必须能导出成人类可读、可 diff、可版本化的文件；
  换模型、换通道、换记忆引擎之后仍是它。开源不等于开放格式，SQLite 里的记忆不算可携带。
  **落地（2026-11-16 批次 3）**：`ops/export-subject.py` 把人格 / 记忆 / 画像 / 关系 /
  纠正 / 跟进合成一个带 `manifest.json`（每片 sha256）的目录；JSON 排序缩进、JSONL 每行稳定、
  统一 LF，可直接进 git。`--verify` 做往返自校验。向量、密钥、聊天历史刻意不导出。
- **可授权性（C）**：能办小事，但每次副作用**可追溯、可回滚、需授权**；
  不做无人监督的自主规划与不可逆执行。这是 2026-11-10 删除 `agentd` 时「先有审计层」那条前提的正解——
  补审计层，而不是永远放弃执行能力。
  **落地（2026-11-16 批次 4）**：核对后发现旧前提从未兑现——`approval.py` 只是内存 Future，
  无队列 / 落盘 / 超时，也没有审批命令。新增 `app_core/audit.py`：写类副作用逐条记
  `data/audit.jsonl`（含 `prev_hash` 哈希链、可回滚标记），状态追加而非覆盖；
  `/audit` 查看、`/approve <id>` 批准后才重放执行（10 分钟过期）。
  `tools.require_approval` **默认关**，旧行为不变；开启后模型不能悄悄写入。
  本批**不新增自主执行能力**，只把责任边界补齐。只读 MCP 与人格自学习排到批次 5——
  它们正好需要这套审计层先稳定。

## 4 · 明确不做

多租户 / 插件市场 / 公网 Web 界面（本地运维面板不受此限）、无人监督的多步任务编排、
通用助手、「更像人」的静默遗忘与失真、把身份绑死在单一模型或存储上。
**不做 D：陪伴记忆引擎**——那是 Mem0 / Zep / memU 的生态位，正面比可替换零件没有胜算。

## 5 · 五条判据（加东西之前）

1. **会不会让「还是它」更稳？**（连续性）
2. **换掉这块，用户能不能从别处轻易得到？** 能 → 接外部；不能 → 自研。
3. **能不能完整带走？**（可携带性）
4. **失败时能否降级、说清、回滚？**（可审计）
5. **会不会让表达污染事实，或让事实压过人？**

第 2 问取代旧定义四问（「它读什么记忆、写什么记忆」等）——
后者在单人项目里变成了「任何新能力先自证与记忆有关」的税。

## 6 · 工程原则

1. **决策附带数据**：记录备选、依据与代价。
2. **影子实验必须有截止时间**，到期转正或移除；且只用于不可逆或有争议的改动，
   可逆改动直接上 + `check()` + 开关。判据与截止日见 [04-评测与实验](04-评测与实验.md)。
3. **约定由工具强制**：分层、接口实现为 lint，不靠自觉。
4. **优先处理静默失败**：不报错但让效果变差的问题，优先补可观测性。
5. 回复时限（宽松总上限 / 无进展超时）、单进程、会话锁都是**实现细节**，
   不写进定义，也不冒充身份特征；可随体验需要调整（2026-11-16 已由 45 秒总闸改为双层时限）。
6. 定义每改一次，CHANGELOG 写清「上一版为什么不够用」。

## 7 · 已定决策

| 决策 | 备选与代价 | 依据 |
|---|---|---|
| 通道抽象为能力声明 + 发送原语 | 直接调平台 SDK 更快，但每个通道都要重写会话循环 | `app_core/runner.py`；QQ / 飞书 / 终端三实现共用 |
| domain 不得依赖 orchestration | 自由 import 更省事，但纯规则会绑上会话状态 | `ops/lint-layers.py` 强制，反向验证过 |
| 记忆置于历史之后、画像作稳定前缀 | 置于之前更符合直觉，但前缀变化会让缓存失效 | 实测缓存命中率 44.9%（2026-11-06） |
| 表情包阈值按情绪分三档 0.12 / 0.16 / 0.08 | 单一阈值无法覆盖负向词 | 正向 3 句可达 0.28，负向同等句数仅 −0.20 |
| 表情包 base64 发送、压到长边 800 | 传路径最简单，但 OneBot 容器内看不到宿主路径 | 926KB → 86KB 后送达 |
| 回复默认 model-first + 信号包 | 继续加规则更可控，但 prompt 会越来越碎 | `style_mode` / `context_format` 可一键回退 |
| `reply()` 拆为四段流水线 | 不拆也能跑，但每次修改要通读全文 | 纯移动，由离线用例保障 |
| 插件只调 `CORE_API` 白名单成员 | 自由调用更灵活，但内部结构会被外部固定 | `ops/lint-plugins.py` 校验 |
| **2026-11-16 重定义 A+B+C** | 沿用「记忆是本体」可继续自研，但会与 AstrBot / Mem0 / Zep / memU 正面比可替换零件 | RealCompanion 3.4% / 96% / AUROC 0.530；12 天内定位漂移 5 次，见 §12 |

## 8 · 内核与外包

**判据四问**：影响每一轮？跨轮记住？失败可降级？数据长期滞留？
一句话：**这次调用的结果，要不要影响下一次？** 要 → 内核；不要 → 外包。
自研还是接外部，先过 §5 的「不可替代性」一问——本判据只划分内核 / 外包，不是产品判据。

| 内核（自己做） | 外包（引外部） |
|---|---|
| 记忆 / 情绪 / 判断 / 节奏 / 人格 / 对话组装 / 调度 / 关系 | ASR / 视觉 / 搜索 / LLM / 嵌入 / TTS / 文件解析 |

边界：知识库、任务、表情归内核（带状态）；原料（抓取/解析）可外包。
代码约定：外包模块 `web` `asr` `llm` 只允许 `chat` `chat_turn` `memory` `tools` `engine` `group` `perception` import，
`lint-layers` 的 `check_outsourced` 会 WARN。

**换掉它还是不是「它」**：这里指**能力缺失**，不是更换实现。按可携带性，
记忆引擎、模型、通道都可替换；不可替换的是判断 / 分寸与身份文件本身。

## 9 · 契约与状态

`MemoryPort` 是契约不是新库：入口只调 `recall / remember / forget`。
「这一轮读了什么」不是第四个方法，而是 `recall(..., trace=[])` 的可选入参——
轨迹由调用方持有，因为 port 是进程内单例，挂在实例上会被并发轮次覆盖。

| 类型 | 读 | 写 | 接口 |
|---|---|---|---|
| fact / knowledge / profile / task | ✅ | ✅ | `MemoryPort` |
| mood | ✅ | ✅ | `AffectPort`（单例状态，不是可枚举条目） |

- **契约宽度 = 实现宽度**：`MEMORY_TYPES` 只声明已实现类型；未实现调用显式报错，不返回空列表。
- 存量直连由 `ops/lint-plugins.py` 的 `_MEM_ALLOWED` 冻结（文件 → 模块 → 符号）；迁移一个删一条。
  这是渐进迁移脚手架，不是永久门禁，收尾后应删除。
- `task` 状态机 `todo → confirming → done | cancelled | expired`；`forget(task)` = 取消，不物理删。
- **回话自检**：模型在正文前写一行 `[自检] 主=… 次=… 依据=… 来源=…`，代码在发送前与入库前各剥离一次，
  写 `data/self_check.jsonl`。**P1 只观测、不改回复**；标签稳定后才做两段式路由。
- **语音输入**：`录制 → ffmpeg 16k wav → VAD → glm-asr-2512 → 场景标注 → 对话`；
  ≤30 秒 / ≤25MB，超了直接说「没听清」不截断；默认不存原音频；
  不做说话人分离、听歌识曲、TTS。

## 10 · 质量与运行数据

以自动验证替代人工确认。CI 每次推送跑 18 套，云端 `ops/verify.sh` 再跑五件套。
**2026-11-15 实测**：离线回归 735、联动体检 46、全链路 280、插件启动 7；
另有通道无关层 7、命令层 11、engine 7、identity 6、delivery 25、approval 10、面板 48。
逐项对应哪条链路见 [02-系统与扩展](02-系统与扩展.md)。

**2026-11-06 历史快照（非实时）**：持续运行 5.8 天；消息 1,363 条（用户 673 / 机器人 690），
日均 233 条；模型调用 2,111 次，输入 4.25M / 输出 216K tokens；成本 5.93 元，
缓存命中 142 万 tokens、命中率 44.9%；长期记忆 132 篇 / 679 条原子事实 / 132 条向量；知识库 26 页。

## 11 · 风险与限制

| 风险 | 应对 |
|---|---|
| QQ 无个人号官方接口，依赖第三方 OneBot 实现；2026-11-09/10 SnowLuma 转私有、NapCat 停更 | 平台隔离在最外层；每 5 分钟探测登录；[03](03-运维与通道.md) 记录迁移路径 |
| 账号风控、飞书凭证泄露 | 独立小号；Secret 只存云端 `keys.json`(600)，可随时重置，scope 最小化 |
| embedding 供应商单点（语音已双 provider 互备） | 待办：兜底与切换 |
| 单用户、单进程 | 不以用户量作指标，以运行数据说明使用强度 |
| 记忆效果缺量化 | 影子采样、周报指标、判据与截止日期，见 [04](04-评测与实验.md) |

## 12 · 依据与沿革

| 依据 | 关键数字 | 日期 |
|---|---|---|
| RealCompanion（arXiv 2610.01780） | 10 段真实关系 / 27,218 条消息 / 最长 120 天；仅 **3.4%**（严格 1.3%）消息需要回忆；所需消息中位在 **2,157 条**之前；池化消融 **96%** 增益落在不需要记忆的探针；检索门控 AUROC **0.530**；把同样 10 条标成「记忆」多用 **10–14 个点**；不加选择塞 10 条使误触发 **0 → 60.8%** | 2026-10 |
| 第三方同对话实测 | 五套记忆系统最高召回 57.6%，远低于厂商自报 80–93%；每轮跑抽取模型的方案写入 1.5–4.2s 且召回不占优 | 2026-09 |
| 生态现状 | AstrBot 47.0k stars / 1000+ 插件；Mem0 / Zep / Letta / memU 把长期记忆做成可插拔基础设施；MCP 标准化工具接入；截至 2026-11-08 记忆内容仍无公认交换格式 | 2026-11-16 |

厂商自报基准分（memU 92.09% LoCoMo、Mem0 92.5/94.4）只作参考，不与第三方实测混用。

**沿革**：12 天内定位被重写至少 5 次——QQ 陪伴机器人（11-04）→ 通道无关的陪伴引擎（11-10）
→ 记忆体 / 对话只是端口（11-11）→ 接住（11-12）→ 自托管长期记忆陪伴体（11-15）
→ 现行定义（11-16）。每次都是代码先越界、文档后补辩护。旧「记忆是唯一主链路」已归档，
但「接住」三条判据、「表达不污染事实」、`docs/04-评测与实验.md` 的分层探针设计仍被本篇继承。
