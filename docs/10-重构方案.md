# 重构方案：从「对话中心」到「记忆契约」

> 依据 [09-设计初衷](09-设计初衷.md)。目标不是重写，是把**记忆从子系统提升为契约**，
> 入口从「直接调存储」改为「只调契约」。分阶段、可回滚、不改表。

## 一、目标架构

```
入口：chat / commands / tools / scheduler / proactive
        │  只依赖 MemoryPort
        ▼
MemoryPort：recall / remember / forget / explain
        │  按类型路由
        ▼
五类记忆：fact / profile / knowledge / mood / task
        │  各自策略（TTL、置信度、生命周期）
        ▼
存储：SQLite / JSON / Markdown（不变）
```

- **MemoryPort 是契约**（Protocol），不是新库、不是新进程。
- 入口不再 `import memory / profile / wiki / diary`。
- 类型由 `MemoryType` 定义；新增类型只扩展契约，不改入口。

## 二、五类记忆的契约

| 类型 | 现有存储 | 生命周期 | 写入时机 | 读取时机 |
|---|---|---|---|---|
| fact | `livingmemory.documents/atoms` | 软删 + 时效 | 总结、工具 | 每轮召回 |
| profile | `profile.json` | 周更、会过期 | 复盘 | 稳定前缀 |
| knowledge | `wiki_pages` | TTL（14/30/180 天） | `note_write` | 索引 |
| mood | `mood/state.json` | 衰减 | 每轮 | 表达 |
| task | `followups` / `reminders` | 关闭即终 | 对话 | 主动消息 |

**统一字段**：`text / type / source / created / last_used / confidence / expires / supersedes`。
存储可以各异，语义必须一致。

## 三、阶段与验收

| 阶段 | 做什么 | 验收 | 回滚 |
|---|---|---|---|
| **P0**（1 天） | 定义 `MemoryPort` + `MemoryType` + 只读适配器（不接入口） | 契约测试：五类各返回统一结构 | 删文件 |
| **P1**（3 天） | `chat_turn` 的**读取**改走 Port，返回与旧路径一致 | 647 离线 + 239 全链路不变；影子对比召回结果 | `memory_port=off` |
| **P2**（3 天） | **写入**改走 Port（总结/画像/知识），双写校验 | 新旧写入逐条对比，差异为零才切 | 同上 |
| **P3**（2 天） | commands / tools / scheduler / proactive 接入 | 43 联动 + 命令/主动消息回归 | 按入口开关 |
| **P4**（2 天） | `explain`：每条回复可追到读了哪些记忆 | `/debug trace` 可用 | 只读功能 |

**硬约束**：P0–P4 不改表结构、不迁移数据、不改通道。

## 四、失败模式与缓解

| 失败模式 | 表现 | 缓解 |
|---|---|---|
| 召回结果变化 | 回复质量波动、记忆引用变少 | P1 影子对比：同批消息新旧召回差异 > 20% 即停 |
| 写入丢失/重复 | 记忆变少或重复 | P2 双写 + `range_key` 幂等；差异为零才切 |
| 性能下降 | 首字延迟上升 | 每阶段跑 p95 延迟；超 10% 回退 |
| 类型混淆 | 情绪被当事实、临态进记忆 | 契约测试：每类的 TTL/写入判据断言 |
| 抽象泄漏 | 入口又直接 import 存储 | lint：入口禁止 import `memory/profile/wiki/diary` |
| 万能层 | 什么都往记忆塞 | 类型白名单；新增类型需过 [09](09-设计初衷.md) 四条判据 |
| 迁移半途 | 新旧两套并存、无人敢删旧路 | 每阶段独立开关；P4 后一个月再删旧路径 |

## 五、规范（新增/修改代码必须遵守）

1. **入口只调 MemoryPort**，不 import 具体存储模块（lint 强制）。
2. **每次写入带 `source` 与 `ts`**：来自哪轮、哪个工具、哪次复盘。
3. **新记忆类型四件套**：时长、置信度、写入判据、读取场景，缺一不可。
4. **`forget` 必须真删或可清理**，不能只改状态。
5. **`explain` 必须可回答**：这轮读了哪几条、为什么选它们。
6. **不改表**：契约层做映射，存储保持原样。

## 六、边界（不做）

- 不做多用户、不做通用助手、不做无记忆对话（见 09）。
- 不搬存储、不改 schema、不换模型、不换通道。
- 不为"纯粹"重写：每阶段都是纯移动或双写，不做大爆炸。

## 七、维护与扩展

| 要加什么 | 怎么加 | 需要改入口吗 |
|---|---|---|
| 新记忆类型 | `MemoryType` + 策略表 + 适配器 | 否 |
| 新入口 | 实现 `Channel` + 调 `MemoryPort` | 否 |
| 新存储后端 | 实现 Store 适配器 | 否 |
| 新召回策略 | Port 内部换实现 | 否 |

**观测**：每条回复带 `memory_trace`（读了哪些 id、命中哪条策略），进日志，可被 `/debug trace` 查。
