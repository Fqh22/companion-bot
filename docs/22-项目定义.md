# 22 · 项目定义

> 2026-11-16 · 状态：稳定（现行定义）
> 取代 [09-设计初衷](09-设计初衷.md)（已归档）。用户圈定方向 **A + B + C**，不做 D。
> 为什么改：见 `CHANGELOG.md` 2026-11-16 条目；逐项落地细节见 [21-改动台账](21-改动台账.md)。

## 1 · 一句话

**它是一个可携带、跨月连续的陪伴主体**：记得住你说过什么，更知道什么时候不该提、
怎么说才不冒犯，并且能在你授权下把小事办完。

不是聊天机器人，不是记忆库，不是任务执行器。本体是**一个「谁」**——跨会话、跨通道、
跨模型仍被认出来的同一个人。

## 2 · 本体

记忆、表达、判断是它的**能力**，不是它的身份；通道、模型、记忆引擎都是可换的**零件**。
换掉零件之后还是它，是我们判断「自研还是接外部」的唯一标准。

旧定义把可替换的零件（记忆存储）当成本体、把不可替代的东西（分寸）当成端口，
于是每次做表达层的事都要先写一段辩护状。**这里把这个关系倒过来。**

## 3 · 三条支柱（有主次）

| | 支柱 | 内容 |
|---|---|---|
| **第一** | **判断 / 克制** | 听见了吗、有去处吗、剂量对吗；真正的接住包含「不接」。最难也最稀缺的是**什么时候不检索、不追问、不主动开口** |
| 第二 | **记忆（资源）** | 事实可追溯、矛盾可裁决、表达不污染事实；只在该用的时候被调用，不是每轮都翻 |
| 第三 | **表达（出场）** | 语气、节奏、形式、沉默；形式本身携带意图（[19-表达与平台抽象](19-表达与平台抽象.md) 的 `Part`） |

第一支柱不是修辞偏好：真实陪伴流量里只有约 3.4% 的消息真的需要回忆过去，
而「要不要检索」这一步几乎所有系统都做不好（依据见 §8）。

## 4 · 三个不可让步的属性

- **连续性**（A）：一个主体、一段关系；不做多租户，不做一人千面。
- **可携带性**（B）：人格、记忆、关系状态必须能导出成**人类可读、可 diff、可版本化**的文件；
  换模型、换通道、换记忆引擎之后仍是它。开源不等于开放格式，SQLite 里的记忆不算可携带。
- **可授权性**（C）：能办小事，但每次副作用**可追溯、可回滚、需授权**；
  不做无人监督的自主规划与不可逆执行。这是 2026-11-10 删除 `agentd` 时「先有审计层」那条前提的正解——
  补审计层，而不是永远放弃执行能力。

## 5 · 明确不做

- 不做平台 / 插件市场 / 多租户 / 公网 Web 界面（本地运维面板不受此限）。
- 不做无人监督的多步任务编排、不做通用助手。
- 不做「更像人」的缺陷：静默遗忘、事实失真、人格随意漂移。
- 不把身份绑死在单一模型、单一通道或单一存储上。
- 不做陪伴记忆引擎（D）：那是 Mem0 / Zep / memU 的生态位，正面比可替换零件没有胜算。

## 6 · 判据（加东西之前，五问）

1. **会不会让「还是它」更稳？**（连续性）
2. **换掉这块，用户能不能从别处轻易得到？** 能 → 接外部；不能 → 自研。（不可替代性）
3. **能不能完整带走？**（可携带性）
4. **失败时能否降级、能否说清、能否回滚？**（可审计）
5. **会不会让表达污染事实，或让事实压过人？**（保留自 09）

第 2 问取代旧定义「它读什么记忆、写什么记忆？答不上来就不加」——
后者在单人项目里变成了「任何新能力先自证与记忆有关」的税。

## 7 · 工程原则（修订）

- 影子实验**只用于不可逆或有争议**的改动，且必须有截止日；可逆改动直接上 + `check()` + 开关。
- 契约是默认路径，不是门禁；存量迁移收尾后删除 `_MEM_ALLOWED` 白名单。
- 45 秒硬线、单进程、会话锁是**实现细节**，不写进定义，也不冒充身份特征。
- 定义每改一次，CHANGELOG 必须写清「上一版为什么不够用」。
