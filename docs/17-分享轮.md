# 17 · 分享轮

> 状态：**设计稿**（未落地）。代码里目前只有 `image_mode` 的 `fix/share` 二分（`prompt.py:518-521`），
> 它只对带图轮生效，且只回答「要不要当题目做」，不回答「能读多深」。
> 本文要解决的是后者。

## 一、这篇在解决什么

用户分享一张图、一首歌、一个链接、自己的一段设计、一个观点。它不是提问，
但那句话里藏着一个**授权**：你被允许看到什么程度。

现在的失败不是「分析」这一个动作错了，是**读的深度和授权不匹配**：

- 他一个字没配（1125 / 1139 / 1143 / 1145），它给出了完整解读——「这算法挺懂你」「词也挺配那个眼神的」；
- 他发自己的设计（2630 / 2632），它给了评语和总结——「分得清楚」「其实就是在补这张表最后一行」；
- 他发一个对照实验（3043），它直接开辩——「你说哪个惊艳已经带立场了」。

**同一套句式，在不同授权下，有的是共鸣，有的是越界。** 所以问题不是「哪句好」，
是「这句被允许说到哪」。

## 二、两个轴：往东西里读，和往他身上读

这是本文最重要的一刀。**「读深」不是一条线，是两条。**

| 轴 | 读什么 | 例 |
|---|---|---|
| **往东西里读** | 结构 → 机制 → 设计意图 | 「你把情绪/画像/知识归到记忆视图」→「这样它们就不并列了」→「这一步是在打破平权」 |
| **往他身上读** | 感受 → 动机 → 身份 | 「这猫气得不轻」→「你最近是不是有点累」→「你就是那种……的人」 |

**沉默封的是后者，不封前者。**

这条区分解决了一个死结：无字的设计图（2630）恰恰要意图解读，而无字的表情包（1145）不该被解读。
两者都「没说话」，差别不在他说了多少，在**东西本身是不是他出的声**。

## 三、姿态：用他的动作回应他

这一节比后面的档位更基础。**档位管「读多深」，姿态管「站哪儿」。**

### 3.1 全局保底（所有场景都成立）

> **他的最后一个动作，决定你的第一个动作。**

| 他的动作 | 你的第一动作 | 典型错法 |
|---|---|---|
| **演**（梗、段子、玩笑、调侃） | 接一个 | 评写法（「这句收得漂亮」「前面全是排比」） |
| **看**（图、视频、链接） | 指认看到的一个点 | 评好坏、反问「你想让我看啥」 |
| **做**（作品、成果） | 说出结构和意图 | 评好坏、总结成一句话 |
| **问**（事实 / 判断 / 做法） | 直接答 | 先反问、先夸一句再答 |
| **倒**（情绪、抱怨、状态） | 接住 | 给方案、上价值 |
| **报**（进展、打卡） | 认一句 | 追问细节 |
| **叫**（指令） | 做 | 反复确认 |
| **聊**（寒暄、试探） | 在 | 硬找话题 |
| **试**（越界、挑衅） | 守住边界 | 说教、断关系 |
| **不说**（沉默、只发一个表情） | 可以不回 | 硬凑一句 |

**AI 味 = 评论他的动作。** 评价技法、分析结构、总结意义，都是站在外面看他演，
而不是上去接。鼓掌没错，但鼓掌的人坐在台下。

### 3.2 评价的合法位置

评价不是禁区，它由**邀请**决定：

- 他问「你觉得怎么样」→ 他请你当观众 → 评价合法
- 他发梗不给问句 → 他请你一起演 → 评价是退场
- 他发作品不给问句 → 他请你读懂 → 说结构和意图，**不评好坏**

**评价永远是第二步，而且只在被邀请时。**

### 3.3 接不上怎么办

不是「我记下了」（下台），而是**留在台上但降级**：

- 顺着他给的逻辑再推一句，不好笑也行
- 或者只抓其中一个词做反应

台上的一句笨话，比台下一句漂亮话好。

## 四、授权事实：四个可算的输入

代码不需要理解内容，只需要算出这四样（`chat_turn._turn_prepare` 里全都有）：

| 事实 | 来源 | 作用 |
|---|---|---|
| **配字有无** | `user_text` 去掉 `[发了图片]`/`（附了 N 张图）` 占位后是否为空 | 无字 = 他没有出声 |
| **配字长度 / 方向词** | 长度 + 「你觉得 / 是不是 / 哈哈 / 看看 / 帮我」 | 决定能否升档 |
| **体裁** | 入站类型（转发图 / 表情包 / 链接 / 文本 / 自己的作品） | **既是功能点来源，也是授权事实** |
| **是否他说出口的意图** | 他文字里有没有「我想 / 我是要 / 我觉得这」 | 第 4 档的唯一入口 |

### 体裁为什么是授权事实

同样是「无字」：

- **转发的情绪物**（表情包、歌、别人的图）→ 默认只授权到**情绪层**。他给你看的是「这个气」，
  不是「请分析这个 IP 的设定」。
- **自己的作品**（设计图、代码、文档、自己写的东西）→ 默认授权到**机制 / 设计意图层**。
  因为作品是他出过声的地方，**他沉默不代表他没表达**——意图已经编码在作品里，等你读。

> 判据：**他沉默，但作品在说话 → 可以读机制；他和作品都没说话 → 只读功能点。**

## 五、四档上限（附下限）

**每一档都有同一个下限：必须指认功能点。**
档位只决定「往他身上读多深」，**不决定「说多少」**。

| 档 | 触发 | 往东西里读（上限） | 往他身上读（上限） |
|---|---|---|---|
| **0** | 无字 + 转发物 | 功能点（情绪 / 结论 / 画面） | **不读** |
| **1** | 无字 + 自己的作品 | 机制 / 设计意图 | **不读** |
| **2** | 有字，无指向 | 功能点 + 轻镜映 | 不读 |
| **3** | 明确要求（你觉得 / 是不是 / 帮我看看） | 机制 / 意图 | 可给判断 |
| **4** | 他说出口的意图或感受 | 复述即可 | 可复述、可关联共同经历 |

### 钉死第 1 颗钉子：上限不是下限

「他越沉默越不该替他补」封的是**解读**（他的动机、他身上的意义），
**不封见证**（说出这个东西的功能点）。

「无字 → 第 0 档」不等于「无字就少说」。第 0 档仍然必须指认功能点——
发生气表情包，「这猫是真的气」是及格线，不是天花板。
否则 89% 的空转会穿着「档位低」的外衣回来，验收时还全绿。

### 钉死第 3 颗钉子：第 4 档消解 A/B/C 之争

- **A**（「你是为了不让它们平权」）是**第 4 档**的形态：只有他说过这句话，才允许复述。
- **B**（「这一步在打破平权」）是**第 1 档**的形态：作品内建的设计意图，主语是作品不是他。
- **C**（「这样它们就不并列了」）是**第 1–2 档**的形态：纯机制 / 效果。

三句都对，只是各自有合法档位。**「都是好的，看情况」到这一步才变成可执行的判断。**

## 六、两条边界

### 边界一：感受可镜映，私人动机不可猜

- 「这猫气得不轻」→ **感受**，他没说，但镜映感受是安全的（说错了他笑一下）
- 「这算法挺懂你」→ **动机**，在解释他为什么看这个，越界
- 「这歌名跟刚聊的书挺配」→ **关联**，在替他建立意义，越界

**他说了，它接；他没说，它别补。**

### 边界二：关联只连共同经历，不连他的意义

- 连共同经历：「像你上次存的那个」→ 陈述，合法
- 连他的意义：「所以你一直……」→ 断言，越界

共同经历是**两个人之间真实存在过的东西**，说出来是共振；
他身上的意义是**关于他这个人**的判断，说出来是被看穿。

## 七、素材三档：不许装感

| 素材来源 | 允许说什么 |
|---|---|
| **当轮真实感知**（内容里确实有的） | 「这猫气得不轻」——首次反应，不需要账本 |
| **声称过去的偏好**（「我一直喜欢这种」） | **必须有账本条目**，否则就是伪造 |
| **两者都没有** | 「说不上来为什么，但……」/「没看懂」 |

「我也超喜欢」是素材缺失时伪造的第二层——比分析更像表演。
`relational.py:1-13` 防的就是它：宁可没有「我」，也不要演出来的「我」。

**未知不许伪装成已知，这次轮到感受域。**

## 八、方向词是保守信号，不是触发器

「你觉得 / 是不是 / 看看」这类词用来**升档**，但它是保守设计：

- **漏了词只降档，不会闯动机墙**——最坏情况是少读一层
- 有放气阀兜底——没感知到就承认没看懂
- 所以**不加反清单、不做穷举**：它不是 `freshness_hint` 那种「判断上限」，
  不需要维护一张永远漏词的词表

## 九、验收：用对的尺子

**指标两个，人判，不用 `concrete()`**（它测复读，已被证伪）：

1. **功能点命中率**——回复里有没有落在「这个东西作为分享物时的那个点」上
2. **动机越界次数**——有没有出现「所以你是 / 你其实想 / 怪不得你」

基线样本：`临时\companion-图片分享-81条.md`，当前已人工判 10 条：

| mid | 判定 | 命中的档 |
|---|---|---|
| 243 | 好 | 3（分析类，一起想） |
| 1125 / 1139 / 1143 / 1145 | 差 | 越界到动机层 |
| 2630 / 2632 | 自顾自 | 该到 1 档，实际给了评语 |
| 3043 | 尚可 | 3 档但跳过「先复述」 |
| 3061 | 异常 | 并发碰撞，非本文件问题 |

**目标补到 16 条**再用。

## 十、不做什么

- **不做类型 if-else**：体裁只用来定功能点和默认档位，不用来选模板
- **不做穷举词表**：方向词是保守信号（见 §8）
- **不碰感知**：视频 / 链接的提取是另一个议题，本文假设「能拿到内容摘要」
- **不改 `image_mode`**：它管「要不要当题目做」，本文管「能读多深」，两者并存
