# 05 · 改动台账

> 用途：每一项改动的细节都落在这里，按编号分节，不散在聊天记录里。
> 新增编号只能追加，不改旧条目；状态用 `进行中 / 已提交 / 已部署 / 已验证`。

## 字段

| 字段 | 说明 |
|---|---|
| 动机 | 为什么改，不改会怎样 |
| 改动 | 文件路径 + 具体改动点 |
| 本地检查 | 实际跑过的命令与数字（不写「应该没问题」） |
| commit SHA | 由 git 记录（`git log -1`）；台账不重复写 SHA，避免自引用 |
| 部署 SHA / 云端验证 | `.deployed_sha` 与 `verify.sh --pre` / 全量结果；纯文档改动写「不适用」 |
| 状态 | 见上方四种 |
