# proactive

主动消息。机器人自己找话聊，但要有节制。

## 规则

| 约束 | 值 |
|---|---|
| 允许时段 | 9:00–23:00 |
| 最小间隔 | 2 小时 |
| 刚聊过不打扰 | 20 分钟内有人说话就跳过 |
| 每日上限 | 4 条 |
| 触发概率 | 每 30 分钟一轮，35% 概率 |

## 话题来源

1. 60% 概率取 `learn/curious.md`（还没搞懂的事），随机且避开上一条
2. 否则按「最近在忙什么」召回记忆

## 配置

阈值目前写在 `plugins/proactive/__init__.py` 顶部常量里，尚未进 `config.yaml`。
