# schedule

启动定时任务与启动期索引，本身不注册命令。

## 启动时做三件事

1. `Scheduler.start()` —— 60 秒一轮的定时器（`app_core/scheduler.py`）
2. `kb.index()` —— 知识库增量向量索引
3. `meme.ensure_vectors()` —— 表情包 caption 向量补齐

## 定时任务表

| 时间 | 任务 |
|---|---|
| 每小时整点 | 知识库增量索引 |
| 03:40 | 复盘 |
| 04:00 | 间隔重复复习 |
| 04:30 | 记忆归档 |
| 23:45 | 写日记 |
| 周日 21:00 | 周报（推送给管理员） |

## 注意

- 定时器用「当天是否已执行」去重，进程重启不会重复跑。
- 长任务都是 `asyncio.create_task` 甩出去，不阻塞事件循环。
