# group · 群聊

群聊是**独立链路**，和私聊（`plugins/chat`）不共用任何状态。设计见
[01-系统](../../docs/01-系统.md)。

## 它做什么

群消息 + @机器人 → 限流 → `app_core.group.GroupCore` 纯对话 → 分段发出。

## 它故意不做什么

| 不做 | 原因 |
|---|---|
| 写长期记忆 | 群友的话会进他的私有库；反过来可能把私聊内容说给一屋子人 |
| 读写情绪 | 围观者会把状态带偏；情绪属于私聊人格 |
| 注入知识库 | 索引里有求职、家人、财务信息 |
| 任何工具 | `note_write` / `kb_*` / `memory_*` 都是泄漏面 |
| 主动说话 | 群里主动 @ 是灾难 |
| 失败时回话 | 「出错了」比不说话更糟，只写日志 |

## 状态

默认 **关闭**（`group.enabled: false`），且白名单为空时即使启用也不回任何群
（空跑期的状态，用来看有没有误触发）。

## 开启步骤

1. `config.yaml` 里 `group.enabled: true`。
2. `whitelist` 填群号，例如 `[123456789]`。
3. `systemctl restart nonebot`，日志里应出现「已启用，白名单 1 个群」。
4. 看 `usage` 表里 `purpose='group'` 的花费。
